俄语随身学 V2.0（实用口语版）

包含：
- 对话翻译模式：输入中文或俄语、显示双语结果、朗读俄语、收藏表达。
- 语音输入尝试：浏览器支持 SpeechRecognition 时可调用；iPhone Safari 不一定支持。也可用 iPhone 键盘听写。
- 生活实用句：日常交流、购物吃饭、交通问路、校园生活、口腔医学。
- 口语学习卡片、发音提示、场景筛选、收藏、导出。
- 常用口语优先匹配人工整理的表达；未匹配时使用 MyMemory 在线翻译。在线服务有配额和可用性限制，不能保证每次都自然，也不保证比其他翻译引擎更准确。
- 收藏保存在本机浏览器；离线可浏览已缓存页面和静态口语内容，在线翻译需网络。

部署到免费 HTTPS：
1. 创建 GitHub 仓库并上传 index.html、manifest.json、sw.js。
2. 仓库 Settings → Pages → Deploy from a branch → main → /(root) → Save。
3. 用生成的 HTTPS 网址在 iPhone Safari 打开，分享 → 添加到主屏幕。

重要：
这是网页应用原型，不是已上架 App Store 的原生 App。正式语音实时翻译需要稳定的语音识别、翻译和语音合成服务；免费接口可能受限。医学表达用于语言学习，实际临床场景须由专业人员核实。
